# @homeflare/distilled-paperless-ngx

This package is **not a HomeFlare SDK**. It is an unmodified copy of
`@distilled.cloud/paperless-ngx`, generated by the
[distilled](https://github.com/alchemy-run/distilled) pipeline from
Paperless-ngx's own **served** OpenAPI 3.0.3 document (the vendor commits no
spec file — see below), published here under its own name only because
`@distilled.cloud/paperless-ngx` does not exist on npm yet — the kit builds
it in a local clone of `alchemy-run/distilled` but, per house policy, never
pushes to that upstream. See
[`../alchemy/docs/distilled-interim.md`](../alchemy/docs/distilled-interim.md)
for the full route every distilled-sourced vendor package follows, and why
this one exists at all.

⛔ **Do not hand-edit anything under `src/`.** The whole point of the route
above is that this directory is _copied_, not written — a fix belongs in the
distilled clone's `packages/paperless-ngx/`, regenerated, then copied back
here.

## Where the spec came from

Paperless-ngx commits **no** OpenAPI document — a tree search of the vendor
repository at tag `v3.1.1` finds only `src/documents/schema.py` and its
test. The document is generated at request time by drf-spectacular and
served only by a running instance, at `/api/schema/?format=json`. The copy
this package was generated from is the one recorded in
[`../alchemy/codegen/manifest.json`](../alchemy/codegen/manifest.json)
under id `paperless-openapi`: read with no credential from this estate's own
Paperless-ngx instance (loopback, 200, `application/vnd.oai.openapi`), and
pinned to `v3.1.1` by matching the installed `src/paperless/version.py`
against the tag — **not** the document's own `info.version`, which reports
the unrelated string `"6.0.0 (10)"` (`SPECTACULAR_SETTINGS['VERSION']`).
`stacks/distilled-submodules/spec-repos/paperless-ngx/fetch-specs.ts` in the
distilled clone documents how to reproduce this fetch without this estate's
own instance (the vendor's own Docker image, booted with just SQLite, is the
recommended way).

## What's in it

30 service modules, one per Paperless-ngx API tag — `documents`,
`correspondents`, `tags`, `document_types`, `storage_paths`,
`custom_fields`, `saved_views`, `share_links`, `share_link_bundles`,
`workflows`, `workflow_triggers`, `workflow_actions`, `mail_accounts`,
`mail_rules`, `processed_mail`, `users`, `groups`, `profile`, `tasks`,
`trash`, `bulk_edit_objects`, `logs`, `config`, `ui_settings`, `search`,
`statistics`, `status`, `remote_version`, `oauth`, `token` — an Effect-typed
operation per Paperless-ngx REST endpoint (164 of the pinned document's 165
operations; the 165th, `documents_email_document`, is marked deprecated in
the spec and skipped in favor of its successor, generated as
`EmailDocuments`), with `catchTag`-able errors for every status the pinned
document declares plus the ones homeflare-kit's own hand-written client
already maps for this vendor but the document omits (404, 403, 400 — see
the distilled package's `patches/<tag>/_undeclared-errors.json` for the
evidence trail).

```ts
import * as PaperlessNgx from '@distilled.cloud/paperless-ngx'; // aliased onto this package — see docs/distilled-interim.md
import * as Effect from 'effect/Effect';

const program = PaperlessNgx.Services.tags
  .listTags({})
  .pipe(
    Effect.provide(PaperlessNgx.PaperlessNgxProtocol),
    Effect.provide(
      PaperlessNgx.credentials({ token: '...', baseUrl: 'https://paperless.example.com' }),
    ),
  );
```

Kit code never imports `@homeflare/distilled-paperless-ngx` directly —
always `@distilled.cloud/paperless-ngx`, aliased in the consuming package's
`package.json` (`"@distilled.cloud/paperless-ngx":
"npm:@homeflare/distilled-paperless-ngx@<version>"`), so the eventual
cutover to the real published package is a one-line alias swap with no
import changes anywhere in the kit. **This PR does not add that alias** —
see `docs/distilled-interim.md`'s "What NOT to do".

## Updating it

From the distilled clone's `homeflare/paperless-ngx` worktree:

```sh
DISTILLED_SPECS_LOCAL=1 pnpm --filter @distilled.cloud/paperless-ngx run generate
pnpm --filter @distilled.cloud/paperless-ngx run typecheck
pnpm format && pnpm specs:check
```

Then copy `src/` here verbatim, bump this package's own `version` (a patch
release — the generated content changed, not this package's own shape), add
a changeset, and let the kit's normal release flow publish it.
