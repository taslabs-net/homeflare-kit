# @homeflare/distilled-netbox

This package is **not a HomeFlare SDK**. It is an unmodified copy of
`@distilled.cloud/netbox`, generated by the [distilled](https://github.com/alchemy-run/distilled)
pipeline from NetBox's own committed OpenAPI 3.0.3 document
(`contrib/openapi.json` at `netbox-community/netbox@v4.7.0`), published here
under its own name only because `@distilled.cloud/netbox` does not exist on
npm yet — the kit builds it in a local clone of `alchemy-run/distilled` but,
per house policy, never pushes to that upstream. See
[`../alchemy/docs/distilled-interim.md`](../alchemy/docs/distilled-interim.md)
for the full route every distilled-sourced vendor package follows, and why
this one exists at all.

⛔ **Do not hand-edit anything under `src/`.** The whole point of the route
above is that this directory is _copied_, not written — a fix belongs in the
distilled clone's `packages/netbox/`, regenerated, then copied back here.

redistribution of `alchemy-run/distilled`'s own Apache-2.0-licensed output,
and relicensing a copy would misstate what it is. See `LICENSE`.

## What's in it

13 service modules, one per NetBox API tag — `dcim`, `ipam`, `circuits`,
`virtualization`, `tenancy`, `vpn`, `wireless`, `users`, `extras`, `core`,
plus the single-endpoint `schema`, `status` and `authentication_check` — an
Effect-typed operation per NetBox REST endpoint (1,256 total), with `catchTag`-able
errors for every status NetBox actually produces, including the ones its own
OpenAPI document omits (404 on every detail operation, 403 on every read, 400
on every list — see the distilled package's `patches/<tag>/_undeclared-errors.json`
for the evidence).

```ts
import * as Netbox from '@distilled.cloud/netbox'; // aliased onto this package — see docs/distilled-interim.md
import * as Effect from 'effect/Effect';

const program = Netbox.Services.ipam
  .listIpamPrefixes({})
  .pipe(
    Effect.provide(Netbox.NetboxProtocol),
    Effect.provide(Netbox.credentials({ token: '...', baseUrl: 'https://netbox.example.com' })),
  );
```

Kit code never imports `@homeflare/distilled-netbox` directly — always
`@distilled.cloud/netbox`, aliased in the consuming package's `package.json`
(`"@distilled.cloud/netbox": "npm:@homeflare/distilled-netbox@<version>"`), so
the eventual cutover to the real published package is a one-line alias swap
with no import changes anywhere in the kit.

## Updating it

From the distilled clone's `homeflare/netbox` worktree:

```sh
DISTILLED_SPECS_LOCAL=1 pnpm --filter @distilled.cloud/netbox run generate
pnpm --filter @distilled.cloud/netbox run typecheck
pnpm format && pnpm specs:check
```

Then copy `src/` here verbatim, bump this package's own `version` (a patch
release — the generated content changed, not this package's own shape), add
a changeset, and let the kit's normal release flow publish it.
