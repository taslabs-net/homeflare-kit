# @homeflare/distilled-proxmox

This package is **not a HomeFlare SDK**. It is an unmodified copy of
`@distilled.cloud/proxmox`, generated by the [distilled](https://github.com/alchemy-run/distilled)
pipeline from Proxmox VE's own `apidata.js` (the api-viewer's schema — PVE
publishes no OpenAPI document, so this is a hand-written converter over the
vendor's own tree, not the shared OpenAPI dialect every other distilled
package uses), pinned to the vendor's GitHub mirror commit matching this
estate's `pve-manager` 9.2.11, published here under its own name only
because `@distilled.cloud/proxmox` does not exist on npm yet — the kit
builds it in a local clone of `alchemy-run/distilled` but, per house policy,
never pushes to that upstream. See
[`../alchemy/docs/distilled-interim.md`](../alchemy/docs/distilled-interim.md)
for the full route every distilled-sourced vendor package follows, and why
this one exists at all.

⛔ **Do not hand-edit anything under `src/`.** The whole point of the route
above is that this directory is _copied_, not written — a fix belongs in the
distilled clone's `packages/proxmox/`, regenerated, then copied back here.

## What's in it

6 service modules, one per PVE top-level path segment — `access`,
`cluster`, `nodes`, `pools`, `storage`, `version` — an Effect-typed
operation per PVE REST endpoint (680 total, 0 skipped), with `catchTag`-able
errors: the shared HTTP status classes, PVE's global
`ParameterVerificationFailed` (the `{"errors": {field: message}}` envelope
every failed write can carry) and non-retryable `BadRequest` fallback, and
`ClusterNodeUnreachable` (PVE's non-standard 595 for a cluster-forwarded
request that couldn't reach its target node) on the task-management
operations the vendor schema itself marks `proxyto: "node"`.

Task polling belongs in the Alchemy provider: the SDK exports the generated
`getNodeTaskStatus` operation, and the caller owns its bound and failure policy.

Pool, backup-job, metric-server and network-interface missing reads expose precise typed tags
from vendor source at pve-manager 9.2.11. Backup-job absence uses a sole nested
`errors.id`; network-interface absence uses the exact sole `errors.iface` on its
detail GET. Both use the parameter-verification envelope; other validation errors
retain their structured failure. PVE form arrays use repeated keys, preserving
commas within a rule/property value. Scalar comma lists and query binding are
unchanged. Protocol fixtures exercise both the accepted and rejected shapes.

`PoolNotFound` keeps a non-retryable client-error category despite PVE's wire
status 500; the patch matcher records the actual status independently.

Container config GET also exposes `LxcConfigNotFound`, backed by installed
pve-container 6.1.13 and libpve-guest-common-perl 6.0.5 source. This proves only the
node-local config is missing: providers must still check the cluster-wide vmid
with the same credential before considering creation.

```ts
import * as Proxmox from '@distilled.cloud/proxmox'; // aliased onto this package — see docs/distilled-interim.md
import * as Effect from 'effect/Effect';

const program = Proxmox.Services.version.getVersion({}).pipe(
  Effect.provide(Proxmox.ProxmoxProtocol),
  Effect.provide(
    Proxmox.credentials({
      tokenId: 'root@pam!terraform',
      secret: '...',
      baseUrl: 'https://pve1.example.com:8006',
    }),
  ),
);
```

Kit code never imports `@homeflare/distilled-proxmox` directly — always
`@distilled.cloud/proxmox`, aliased in the consuming package's `package.json`
(`"@distilled.cloud/proxmox": "npm:@homeflare/distilled-proxmox@<version>"`),
so the eventual cutover to the real published package is a one-line alias
swap with no import changes anywhere in the kit.

## Updating it

From the distilled clone's `homeflare/proxmox` worktree:

```sh
DISTILLED_SPECS_LOCAL=1 pnpm --filter @distilled.cloud/proxmox run convert
DISTILLED_SPECS_LOCAL=1 pnpm --filter @distilled.cloud/proxmox run generate
pnpm typecheck:ci
pnpm format && pnpm specs:check
```

Then copy `src/` here verbatim and add a changeset. The normal release flow
versions and publishes the package.
